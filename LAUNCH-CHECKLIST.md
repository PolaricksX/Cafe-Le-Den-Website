# Launch Checklist

## Content
- [ ] No placeholder text or `TODO(client)` left
- [ ] Phone, email, address, hours verified
- [ ] Client approved final copy and photos

## Functionality
- [ ] Contact form delivers email to client (test in production)
- [ ] All links/buttons work; phone numbers are tap-to-call
- [ ] Custom 404 page

## SEO
- [ ] Unique title + description per page
- [ ] Sitemap and robots.txt live
- [ ] LocalBusiness schema valid
- [ ] Alt text on all images
- [ ] Search Console verified, sitemap submitted

## Performance & accessibility
- [ ] Lighthouse 90+ on mobile (perf, a11y, SEO, best practices)
- [ ] Images optimized via next/image
- [ ] Keyboard navigation and focus states work

## Deploy
- [ ] Domain connected, HTTPS active, www/non-www redirect
- [ ] Env vars set in hosting dashboard
- [ ] Analytics working
- [ ] Favicon + social share image

## Handoff
- [ ] Logins/ownership transferred to client
- [ ] Handoff doc sent
- [ ] Final payment received; care plan offered
