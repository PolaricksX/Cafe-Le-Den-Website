name: forms
description: Secure contact/quote forms with email delivery.
---
- Next.js Server Action or route handler; validate with zod server-side.
- Honeypot field + basic rate limiting; never trust client input.
- Send email via Resend (API key in env var, server only).
- Accessible labels, inline errors, success/failure states, disabled while submitting.
- Never render user input as raw HTML.
