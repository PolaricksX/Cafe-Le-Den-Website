name: seo
description: Local SEO setup for a Next.js small-business site.
---
- Use the Next.js Metadata API per page (title, description, openGraph).
- Add `app/sitemap.ts` and `app/robots.ts`.
- Add LocalBusiness JSON-LD (name, address, phone, hours, geo, sameAs).
- One h1 per page, descriptive headings, alt text, internal links.
- Include city/service keywords naturally; no keyword stuffing.
